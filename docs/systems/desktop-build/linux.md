# Linux

## Icons

1. `yarn icon:icns` builds the ICNS icon file
2. [`icon-gen`](https://github.com/akabekobeko/npm-icon-gen) is used to convert the `desktop/build/icon.png` to the ICNS format with different icon sizes.
3. `desktop/build/icon.icns` is the file used by `electron-builder` for the application icon.
